# SleepStim Offline Analysis

This directory contains scripts, notebooks, and resources for the offline analysis of EEG data that has been collected and/or processed using the `sleepstim` toolkit.

Subdirectories are generally organized by the specific type of analysis being performed or by project-specific analyses. Examples include:

-   `Behavioral/`: Analyses related to behavioral data.
-   `NIDRA/`: Analyses specific to the NIDRA project or NIDRA-like stimulation protocols.
-   `Resting_State/`: Analyses focusing on resting-state EEG data.
-   `TMS/`: Analyses related to Transcranial Magnetic Stimulation data.
-   `LMM_cluster_perm/`: Analyses involving Linear Mixed Models and cluster-based permutation tests.
-   `Entropy/`: Scripts for entropy-based measures.

Please refer to the README files within each subdirectory for more specific details on the analyses contained therein.
