# Linear Mixed Model (LMM) Cluster Permutation Analysis

This directory contains scripts and resources related to performing statistical analyses using Linear Mixed Models (LMMs) combined with cluster-based permutation tests. These methods are often used in neuroimaging and electrophysiological research to assess the significance of effects across time, space, or frequency while accounting for repeated measures and controlling for multiple comparisons.

The scripts herein likely implement or utilize these advanced statistical techniques for data processed with the `sleepstim` toolkit.
