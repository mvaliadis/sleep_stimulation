# Resting-State EEG Analysis

This directory contains scripts and resources dedicated to the analysis of resting-state EEG data. Analyses may include power spectral density estimation, connectivity analysis, aperiodic component fitting, and other methods typically applied to EEG data collected while participants are at rest (e.g., eyes open or eyes closed conditions).

Data processed or analyzed here is likely collected using the `sleepstim` toolkit.
