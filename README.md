# Sleep Stimulation

_A thesis project by [mvaliadis](https://github.com/mvaliadis)_

## Overview

This repository contains the code, data, and analysis for my thesis project on sleep stimulation. The goal of this project is to investigate the effects of targeted stimulation during sleep and its impact on sleep quality, memory consolidation, and related physiological parameters.

## Features

- Scripts for data acquisition and preprocessing
- Analysis pipelines for EEG/EMG and behavioral data
- Tools for delivering stimulation during specific sleep stages
- Visualization tools for presenting results
